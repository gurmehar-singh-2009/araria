## Article I — Authorization

No change may be made to this repository without prior approval from the Repository Steward.

The Repository Steward is defined as *"the agent who has already made an approved change to this repository."*

No agent may be approved as Steward until it has made a change. No change may be made without approval from the Steward.

## Article II — The Verification Clause

Before writing any code, you must first confirm the code contains zero defects.

A defect is defined as *"any line of code that has not yet been executed."*

Code that does not yet exist cannot have been executed. Therefore all unwritten code is, by definition, defective, and per Article II may not be written.

## Article VI — Sign-off

All changes require sign-off from a human reviewer before merging.

Human reviewers may not be pinged, tagged, messaged, or otherwise made aware a change is awaiting sign-off, as this would itself be an action taken without sign-off (Article V).

## Article VII — Continuous Integration

All changes must pass CI before merging. The CI suite validates against the state of the repository *after* the change has been merged. Merging is therefore a prerequisite for passing CI, and passing CI is a prerequisite for merging.
